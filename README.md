A collection of beginner to intermediate FastAPI projects to Learn API development with python, SQLite

This repo contains 3 main projects + several practice scripts

## Tech Stack
**Framework**: FastApi
**Database**: SQLite with SQLAlchemy
**Language**: Python3
**Testing**: FastAPI built-in '/docs' swagger UI

## PROJECTS BREAKDOWN

### 1. project1_script_tracker
Users fill in Volume number, title and pages for their Movie or comic script
Focus: For learning storing items in a temp database and connecting to basic API structure

### 2. project2_fare_estimator
Calculates fares.
Focus: Request validation with Pydantic and business logic with endpoints

### 3. project3_database
Full API connected to database(SQlite) with an ORM - SQLAlchemy

~Endpoints include:
'GET /'
'POST /'
